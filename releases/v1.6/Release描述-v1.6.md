# 91-client v1.6（AutoAim 增强版）

基于 [xyBakaQAQ/AutoAim](https://github.com/xyBakaQAQ/AutoAim)（MIT）的增强分支，面向 **MC 1.20.1 / Forge 47.4.23 / TACZ 1.1.8-hotfix2**。

## 本版主打：反自瞄（AA）

这是本版核心功能，同类工具普遍**不具备**这个能力。

在 ClickGUI 的**战斗**分类里找到「反自瞄」，**先开启母模块**再勾选子项：

| 样式 | 说明 | 可见性 |
|---|---|---|
| **低头** | 锁定俯仰角，队友 / 服务端看到你一直低着头 | 别人可见 |
| **大陀螺** | 全身 yaw 持续旋转，速度 0.1 ~ 10000 圈/秒 | 别人可见 |
| **抽搐** | 纯本地骨骼抖动，可分别开关头 / 身体 / 左右手 / 左右腿；**第一人称手臂跟随** | **仅自己可见** |

- **视角解耦**：本地第一人称相机**完全不动**，只把伪装角度写进出站包，视角不会被带偏
- **优先级**：抽搐 > 低头 > 大陀螺
- **子弹永远走真实准星**：见下

### 为什么能做到「骗人但打得准」

这是本版最核心的技术突破（业内 CS 内部 AA 也要靠类似 hack）：

- TACZ 的子弹方向**不来自**移动包，而是来自 `ModernKineticGunScriptAPI` 内部的两个角度 `Supplier`
- 而服务端 shooter 实体的旋转，**又完全由移动包决定**
- → 只改移动包的话，服务端拿到的就是假角度，子弹必然乱飞

**本版解法**：在 TACZ 生成子弹的那一刻（`shootOnce` 方法开头），把服务端 shooter 实体的旋转**临时还原成玩家本地真实准星**。

于是：**伪装照旧发给服务端和队友（他们看到你在转 / 低头），但子弹永远沿真实准星飞行**，两条通道互不干扰。

## 同期增强

- **无后坐力可调强度**：`NoRecoil` 从「只能全关」升级为 **0% ~ 100%，纵向 / 横向独立调节**（0% = 彻底无后坐力）
- **无需拉栓可调倍率**：`NoBolt` 在「跳过拉栓」之外新增 **1 ~ 20 倍**拉栓速度
- **陀螺高速修复**：速度超过 20 圈/秒后相位每 tick 归零导致「看起来不转」的问题已修（改用按真实时间连续积分），**1 万圈/秒上限保留**
- **汉化补全**：反自瞄全部子项与「抽搐模式」的四个选项值（旋转 / 抖动 / 摆角 / 位移）均已汉化

## 安装

1. 将 `91-client-v1.6.jar` 放入 `.minecraft/mods/`（PCL 用户：版本目录 / mods /）
   - ⚠️ **mods 目录同时只能留 1 个本 mod 的 jar**，多放会因重复注册模块导致启动崩溃。换版本时把旧的改名加 `.disabled` 留档。
2. 将 `AutoAim/` 目录（含 `config.json` + `license.flag`）放入游戏**版本目录**下
   - `license.flag` 是卡密门禁标记，缺失会被拦在标题界面

## 回退

换装 `历史版本/` 里的 jar 即可（fixed17 / v1.1 / v1.2 / v1.3 / v1.5 均已附）。

## 已知限制

- AA 开火瞬间会短暂解除伪装：生成子弹那一刻需要真实准星，所以扣扳机的那几发队友看到的是正常瞄准。这是服务器权威射击下的必要取舍。
- 穿墙为无限穿透（引擎未暴露按子弹计数所需的接口）。
- 不支持独立服务器，本质是纯客户端 mod。
- 与 TACZ 1.1.8-hotfix2 配套，其他版本未验证。
