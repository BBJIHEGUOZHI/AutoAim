# 91-client（AutoAim 增强版）

基于 [xyBakaQAQ/AutoAim](https://github.com/xyBakaQAQ/AutoAim)（MIT 许可，© 2024 xyBakaQAQ）的增强分支，面向 **Minecraft Java 1.20.1 + Forge 47.4.23 + TACZ（永恒枪械工坊：零）1.1.8**。

本分支是上游的严格超集：保留全部原有功能，新增若干面向单机 / 联机体验的增强。

## 新增 / 增强

- **子弹放大上限 10 → 250**：客户端滑块与服务端安全阀成对放开，联机不会被截回 10。注意：旧存档滑块值仍为 10，升级后需手动把滑块拖到最右才会变为 250；250× 时命中盒半径约 7.8 格，子弹模型与弹孔同步放大，效果夸张，按需调节。
- **子弹穿墙（Wallbang）**：战斗分类新增模块，默认关闭。滑块 1~10 代表最多穿 N 面墙，拉满 = 无限制穿透（滑块显示「无限制」）。
- **联机生效**：`mods.toml` 设置 `displayTest = IGNORE_ALL_VERSION`，好友未安装本 mod 也能进入房主开启的世界并看到效果（谁开房 / 开服谁安装，效果在该世界内全局生效）。
- **存档修复（v1.1）**：修复中文环境下「改动设置 / 按键后重开游戏即回默认」的问题（布尔开关、下拉模式、模块按键的本地化存档）。

## 安装

1. 将 `91-client-beta1.0-v1.3.jar` 放入 `.minecraft/mods/`（PCL 用户：版本目录 / mods /）。
   - ⚠️ **mods 目录同时只能留 1 个本 mod 的 jar**，多放会因重复注册模块导致启动崩溃。换版本时把旧的改名末尾加 `.disabled` 留档，不要删除。
2. 将 `AutoAim/` 目录（含 `config.json` + `license.flag`）放入游戏**版本目录**下。
   - `license.flag` 是卡密门禁标记（1 字节），缺失会被拦在标题界面无法进入。
   - 直接用 `现成参数（加入版本目录就行直接替换）-v1.3.zip` 解压到版本目录即可。
