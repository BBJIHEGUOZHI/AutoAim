# 91-client（AutoAim 增强版）

基于 [xyBakaQAQ/AutoAim](https://github.com/xyBakaQAQ/AutoAim)（MIT 许可，© 2024 xyBakaQAQ）的增强分支，面向 **Minecraft Java 1.20.1 + Forge 47.4.23 + TACZ（永恒枪械工坊：零）1.1.8**。

本分支是上游的严格超集：保留全部原有功能，新增若干面向单机 / 联机体验的增强。

## 新增 / 增强

- **子弹穿墙（Wallbang）真正生效（v1.4）**：战斗分类模块，默认关闭。开启后子弹不再被墙体截断，直接穿透并在墙后命中目标（当前为无限穿透，详见「已知限制」）。
- **配置不落盘修复（v1.4）**：修复中文环境下「改动设置 / 按键后重开游戏即回默认」的问题——布尔开关、下拉模式、数值、文本四类设置与模块按键现在改动即存盘。对应 `Module` 与 4 个 `Setting` 类的改动。
- **子弹放大上限 10 → 250（v1.3）**：客户端滑块与服务端安全阀成对放开，联机不会被截回 10。注意：旧存档滑块值仍为 10，升级后需手动把滑块拖到最右才会变为 250；250× 时命中盒半径约 7.8 格，子弹模型与弹孔同步放大，效果夸张，按需调节。
- **联机生效（v1.2）**：`mods.toml` 设置 `displayTest = IGNORE_ALL_VERSION`，好友未安装本 mod 也能进入房主开启的世界并看到效果（谁开房 / 开服谁安装，效果在该世界内全局生效）。

## 安装

1. 将 `91-client-beta1.0-v1.4.jar` 放入 `.minecraft/mods/`（PCL 用户：版本目录 / mods /）。
   - ⚠️ **mods 目录同时只能留 1 个本 mod 的 jar**，多放会因重复注册模块导致启动崩溃。换版本时把旧的改名末尾加 `.disabled` 留档，不要删除。
2. 将 `AutoAim/` 目录（含 `config.json` + `license.flag`）放入游戏**版本目录**下。
   - `license.flag` 是卡密门禁标记（1 字节），缺失会被拦在标题界面无法进入。
   - 直接用 `现成参数（加入版本目录就行直接替换）-v1.4.zip` 解压到版本目录即可。

## 已知限制

- **穿墙为无限穿透**：1.20.1 的 `ClipContext` 未暴露 `getEntity()`，无法按每颗子弹计数穿透层数，因此「最多穿 N 面墙」的滑块暂未接入（默认值 11 即等同于无限制）。
- **不支持独立服务器（dedicated server）**：jar 内约 50 个 class 引用 `net/minecraft/client/`，本质是纯客户端 mod。谁开房 / 开服谁安装即可。
- 与 TACZ 1.1.8 配套；其他 TACZ 版本未验证。
