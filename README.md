# 91-client（AutoAim 增强版）

基于 [xyBakaQAQ/AutoAim](https://github.com/xyBakaQAQ/AutoAim)（MIT 许可，© 2024 xyBakaQAQ）的增强分支，面向 **Minecraft Java 1.20.1 + Forge 47.4.23 + TACZ（永恒枪械工坊：零）1.1.8**。

本分支是上游的严格超集：保留全部原有功能，新增若干面向单机 / 联机体验的增强。

## v1.6 / v1.6.1 新增：反自瞄（AA）

本版核心功能，同类工具普遍不具备的能力。

- **三种样式，接入战斗分类**：在 ClickGUI 的「战斗」分类里找到「反自瞄」，开启母模块后生效
  - **低头** —— 锁定俯仰角，队友 / 服务端可见你一直低着头
  - **大陀螺** —— 全身 yaw 持续旋转，队友可见你原地转圈，速度 0.1 ~ 10000 圈/秒可调
  - **抽搐** —— 纯本地骨骼抖动，**别人看不见**，第一人称手臂跟随；可分别开关头 / 身体 / 左右手 / 左右腿
- **视角解耦**：本地第一人称相机**完全不动**，只把伪装角度写进出站包，视角不被带偏
- **子弹永远走真实准星**：伪装与弹道是两条独立通道（见下方「技术说明」）
- **优先级**：抽搐 > 低头 > 大陀螺

### 技术说明：为什么 AA 能「骗人但打得准」

这是本版最核心的技术突破，故在此说明：

- TACZ 的子弹方向**不来自**玩家的移动包，而是来自 `ModernKineticGunScriptAPI` 内部的两个角度 `Supplier`
- 而服务端上那个 shooter 玩家的实体旋转，**又完全由移动包决定**
- 所以只要开了 AA，服务端拿到的就是伪装角度 → 子弹乱飞

**解法**：在 TACZ 生成子弹的那一刻（`shootOnce` 方法开头），把服务端 shooter 实体的旋转**临时还原成玩家本地真实准星**。

结果：**伪装照旧发给服务端和队友（他们看到你在转 / 低头），但子弹永远沿真实准星飞行**，两者互不干扰。

## 新增 / 增强

- **反自瞄 AA（v1.6）**：见上。三样式 + 视角解耦 + 子弹走真实准星。
- **无后坐力可调强度（v1.6）**：`NoRecoil` 从「只能全关」升级为 0% ~ 100%，纵向 / 横向独立调节。
- **无需拉栓可调倍率（v1.6）**：`NoBolt` 在「跳过拉栓」之外新增 1 ~ 20 倍拉栓速度。
- **子弹穿墙（Wallbang）真正生效（v1.4）**：战斗分类模块，默认关闭。开启后子弹不再被墙体截断，直接穿透并在墙后命中目标（当前为无限穿透，详见「已知限制」）。
- **配置不落盘修复（v1.4）**：修复中文环境下「改动设置 / 按键后重开游戏即回默认」的问题——布尔开关、下拉模式、数值、文本四类设置与模块按键现在改动即存盘。
- **子弹放大上限 10 → 250（v1.3）**：客户端滑块与服务端安全阀成对放开，联机不会被截回 10。
- **联机生效（v1.2）**：`mods.toml` 设置 `displayTest = IGNORE_ALL_VERSION`，好友未安装本 mod 也能进入房主开启的世界并看到效果。

## 安装

1. 将 `91-client-v1.6.1.jar` 放入 `.minecraft/mods/`（PCL 用户：版本目录 / mods /）。
   - ⚠️ **mods 目录同时只能留 1 个本 mod 的 jar**，多放会因重复注册模块导致启动崩溃。换版本时把旧的改名末尾加 `.disabled` 留档，不要删除。
2. 将 `AutoAim/` 目录（含 `config.json` + `license.flag`）放入游戏**版本目录**下。
   - `license.flag` 是卡密门禁标记（1 字节），缺失会被拦在标题界面无法进入。

## 已知限制

- **穿墙为无限穿透**：1.20.1 的 `ClipContext` 未暴露 `getEntity()`，无法按每颗子弹计数穿透层数，因此「最多穿 N 面墙」的滑块暂未接入（默认值 11 即等同于无限制）。
- **不支持独立服务器（dedicated server）**：jar 内部分 class 引用 `net/minecraft/client/`，本质是纯客户端 mod。谁开房 / 开服谁安装即可。
- **AA 开火瞬间会短暂解除伪装**：生成子弹的那一刻需要真实准星，所以扣扳机的那几发，队友看到的是你正常瞄准。这是服务器权威射击下的必要取舍（业内 CS 内部 AA 同样要在开火 tick 切回真实角度）。
- 与 TACZ 1.1.8-hotfix2 配套；其他 TACZ 版本未验证。
